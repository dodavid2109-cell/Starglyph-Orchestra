# Starglyph Orchestra

Write music in starglyphs. Each glyph of the pentagram lettering system becomes a note or a path of notes, played by an orchestra of recorded instruments (Philharmonia samples) and a studio drum kit.

**Play it:** https://dodavid2109-cell.github.io/Starglyph-Orchestra/

- Type with the glyph keyboard or your own keyboard. Enter plays and stops.
- Each channel reads its glyphs in Path (every stroke of a glyph sounds) or Tone (one note per glyph, from the star's five notes).
- Books on the shelf are saved on your device, with no login. Recordings save as MP3 on the device too.
- Six looks: Game Boy, Desktop, Hi-Fi, Paperback, HUD and Soft.

The site is a single page (`index.html`) that loads each instrument's recordings from `smp/` when a channel first needs them.
